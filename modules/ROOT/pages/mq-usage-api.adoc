== Retrieve Usage Metrics with Anypoint Metering Query API

[NOTE]
These REST APIs are supported on Canada Cloud and Japan Clouds (Hyperforce) only.

To retrieve Anypoint MQ usage metrics on Canada Cloud or Japan Cloud, use the Metering API.

For example, to retrieve effective API requests:

. xref:mq-apis.adoc#get-bearer-token[Get a bearer token] for an Anypoint Platform user account that has the Usage Viewer permission for your root organization.
. Use a command like this:
+
[source,bash,linenums]
----
curl --location 'https://anypoint.mulesoft.com/metering/usage/api/v1/meters:search' \
--header 'Authorization: bearer ***' \
--header 'Content-type: application/json' \
--data '{
    "query": "SELECT effective_api_requests FROM mq_effective_api_requests_count WHERE timestamp BETWEEN 1728874800000 AND 1731610357770 TIMESERIES P1M"
}'
----
+
The output includes:
+
[source,json,linenums]
----
{

}  
----
